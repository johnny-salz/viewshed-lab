04 / Export & diagnostics

Model, limitations & sources

Run from localhost for reliable WebGPU and tile networking: python -m http.server 8000 --bind 127.0.0.1, then open http://127.0.0.1:8000/viewshed_lab_latest.html. ?offline=1 disables automatic real-terrain loading.

The map uses a local spherical AEQD (Azimuthal Equidistant) projection centered on the loaded area. Radial distances and bearings from the center are preserved on the sphere. Earth radius: 6,371,008.8 m. Curvature/refraction correction: −(1−k)d²/(2R).

WebGPU uses a radial prefix-horizon compute pass and screen-space fragment classification. Narrow obstacles and shadow boundaries remain discretization-sensitive. CPU engines are retained for debugging.

Record refinement gives the observer and current GPU endpoint the finest available point tile, then checks promising far sectors along a narrow z12–13 terrain corridor without slowing the live path.

NoData is never replaced by sea level. Base tiles fall back to lower-resolution parents; high-res holes fall back to the global terrain layer. Remaining unknown terrain pauses the live computation under the observer.

Terrain source: Mapterhorn Terrarium WebP in Web Mercator (EPSG:3857), with a global terrain DEM and regional higher-resolution data. This build does not currently integrate a true DSM.

Manual place search uses OpenStreetMap Nominatim only on explicit submit, never autocomplete, with local result caching and a 1 request/s throttle. Nominatim usage policy.
